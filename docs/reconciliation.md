# Daily reconciliation

Reconciliation compares uploaded reports with human operational records. It does not become a second ledger.

The flow is:

1. Select the date.
2. Review uploaded and manual records.
3. Compare expected and posted movement.
4. Match, review, resolve, ignore with reason, or create an explicit adjustment.
5. Audit the resolution.

Differences are not automatically errors or adjustments. Manual-only reseller activity is valid when it has a traceable reference and explicit fulfillment source.
